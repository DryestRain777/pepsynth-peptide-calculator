# Pepsynth Labs — Peptide Reconstitution Calculator

A static, mobile-first web app: reconstitution calculator + reference library for 50+ research peptides.

## Files
- `index.html` — markup (age gate, hero, calculator, guides, library, FAQ, disclaimer)
- `styles.css` — Pepsynth branding (deep navy + electric blue), mobile-first
- `peptides.js` — data for 50+ compounds
- `app.js` — calculator logic, autofill, search/filter, syringe visual

## Run
```
python3 -m http.server 8080
```
Then open http://localhost:8080

## Deploy
Any static host (Netlify, Vercel, Cloudflare Pages, S3) — no build step, no dependencies.
